# User Guide

## Study A Deck

1. Choose a topic deck.
2. Choose all cards or a difficulty level.
3. Read the question.
4. Reveal the answer.
5. Mark the card as known or review later.
6. Reset the session when needed.

## Included Decks

- Computer Science Interviews
- Project Management Interviews

## Tips

- Use `Review later` when you partially know a topic.
- Reset the deck after one pass and filter by harder questions.
- Add new decks in `src/data/seedDecks.js`.
