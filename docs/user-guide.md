# User Guide

## Rehearse An Interview

1. Review the company mission, vision, values, and cybersecurity PM role summary.
2. Start the camera to check framing and presence.
3. Practice smart flashcards.
4. Ask the coach to improve an answer.
5. Join a simulated conference room and answer the panel prompt.
6. Play a logic game to practice risk and dependency reasoning.

## Smart Flashcards

Use the Cyber PM deck for role-specific answers. Use the credential mapper deck to connect certifications to project delivery value.

## Coach Chat

The coach uses a local fallback unless a secure backend endpoint is configured. Do not put OpenAI API keys in browser code.

## Conference Rooms

Each room simulates a different interview stage:

- Recruiter Screen
- Cyber Delivery Panel
- Executive Panel
